Массовый импорт аккаунтов

CSV UTF-8, до 5000 записей. Импорт не авторизует аккаунты и не включает публикации. Добавляйте только аккаунты, которыми вправе управлять.

Формат accounts.csv
username,platform,category,timezone,daily_limit
example_creator,instagram,memes,Europe/Moscow,2

Площадки: instagram (официальный API), instagram_browser (существующий локальный режим), telegram, youtube, tiktok, vk. Для официального API можно указать дополнительные столбцы destination и token_env. token_env — только имя переменной окружения. Для YouTube необходим destination с ID канала. Пароли и токены в CSV не принимаются.
